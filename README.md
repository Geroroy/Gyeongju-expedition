# 경주 탐방 (Gyeongju Expedition)

빨간 점퍼를 입은 고릴라 인형이 되어 경주 시내를 걸어 다니는 3D 오픈월드 웹 게임입니다.
출발 지점은 **황리단길**입니다. 대릉원, 첨성대, 동궁과 월지 같은 명소를 찾아가 스탬프를 모으면 됩니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성 (아무 정적 호스팅에 올리면 됨)
```

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 (카메라 기준) |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 드래그 / 휠 | 시점 회전 / 줌 |
| E | 근처 명소 살펴보기 (설명 카드) |
| F | 자전거 타기 · 내리기 (출발 지점 옆에 대여 자전거) |
| M | 지도 (방문한 곳은 눌러서 빠른 이동) |
| B | 스탬프 도감 |
| N | 낮 ↔ 밤 (동궁과 월지 야경) |
| H | 도움말 |

모바일에서는 화면 왼쪽을 끌면 가상 조이스틱, 오른쪽을 끌면 시점 회전, 두 손가락으로 줌이 됩니다.

## 맵: 실제 경주를 어떻게 옮겼나

- **좌표**: 실제 위경도를 미터 단위 게임 좌표로 바꿨습니다(`src/world/geo.js`). 원점은 황리단길 포석로(35.8375°N, 129.2088°E)이고 1 unit = 1 m입니다. 그래서 명소 사이 거리가 실제와 같습니다. 예를 들어 황리단길에서 첨성대까지 약 1 km, 동궁과 월지까지 약 1.6 km입니다. 화면 오른쪽 아래에 지금 위치의 위경도가 표시됩니다.
- **랜드마크**: 위경도를 그대로 변환했습니다(`src/world/layout.js`).
- **도로·하천**: 포석로(황리단길), 태종로, 첨성로, 계림로, 원화로, 교촌길, 남천, 형산강을 실제 지도를 보고 폴리라인으로 근사했습니다. 차선 하나하나까지 정확하지는 않습니다.
- **건물 크기**: 첨성대(높이 약 9.17 m, 27단), 황남대총(남북 약 120 m의 쌍분, 높이 약 22 m), 천마총(지름 47 m), 봉황대(높이 22 m), 월정교(약 66 m)는 실제 치수를 참고해 만들었습니다.

## 탐방 장소 (스탬프 16곳)

황리단길 · 대릉원 · 천마총 · 황남대총 · 첨성대 · 동부사적지 핑크뮬리 · 계림 · 월성(석빙고) · 동궁과 월지 · 월정교 · 교촌마을 · 봉황대 · 황룡사지(9층 목탑 상상 복원) · 분황사(모전석탑) · 국립경주박물관(성덕대왕신종) · 오릉

10월 경주 분위기에 맞춰 은행나무와 단풍, 황금빛 논, 분홍 핑크뮬리를 넣었습니다.

## 주인공

레퍼런스 사진의 인형을 3D로 옮겼습니다(`src/player/gorilla.js`).
- 짙은 회색 머리, 크림색의 큰 얼굴
- 까만 구슬 눈, 회색 자수 코와 웃는 입, 분홍 볼
- 빨간 후드 점퍼(흰 줄무늬, 소매 로고)
- 크림색 둥근 손발, 오른발 노란 패치

걸을 때는 뒤뚱거리고, 서 있을 때는 숨을 쉬며 고개를 갸웃합니다. 점프하고 착지하면 몸이 살짝 찌그러집니다.

> 점퍼 소매의 로고는 사진 속 인형을 그대로 재현한 것입니다. 게임을 공개 배포한다면 `sleeveLogoTexture()`의 문구를 바꾸는 것을 권장합니다.

## 코드 구조

```
src/
  main.js              렌더러 · 루프 · 키 처리 · 빠른 이동
  styles.css           HUD/모달 스타일
  world/
    geo.js             위경도 ↔ 게임 좌표 변환, 월드 경계
    layout.js          명소 · 도로 · 하천 · 다리 · 구역 · 고분 데이터
    ground.js          지면 텍스처(캔버스, 미니맵과 공유)
    textures.js        한옥 벽, 기와, 첨성대 석재, 벽돌, 간판 등 절차적 텍스처
    builders.js        한옥 · 현대 건물 · 나무 · 고분 · 담장 (InstancedMesh)
    landmarks.js       첨성대 · 월지 · 월정교 · 계림 · 월성 · 황룡사지 · 분황사 · 박물관
    world.js           월드 조립(황리단길 상점가, 동네 채우기, 가로수, 산)
    batch.js           정적 메시 병합(드로우콜 절감)
    collision.js       2D 충돌(원·회전 사각형·물), 지형 높이(월성 언덕, 다리)
    sky.js             하늘 · 해/달 · 그림자 · 낮밤 전환
    npc.js             관광객 NPC(한복 대여객 포함)
  player/
    gorilla.js         주인공 모델 + 애니메이션
    controller.js      이동 · 점프 · 자전거 · 3인칭 카메라
    input.js           키보드 · 마우스 · 터치
  ui/hud.js            지명 표시, 미니맵, 스탬프, 정보 카드, 지도
```

모든 텍스처와 모델은 코드로 생성합니다. 외부 이미지나 3D 에셋 파일은 쓰지 않습니다.

## 디버그

URL 파라미터로 원하는 위치에서 바로 시작할 수 있습니다.

```
/?autostart&x=920&z=345&h=3.14   # 첨성대 앞
/?autostart&night=1              # 밤으로 시작
```

브라우저 콘솔에서는 `__game.player.teleport(x, z)`로 이동할 수 있습니다.
